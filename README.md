# PvZ Fusion English for Android

An English fan translation of Plants vs. Zombies Fusion, using the Blooms community's PC translations with Android UI improvements.

## Download 4.1 pre-release 3

- [Standard English APK](https://github.com/silvershadowkat/pvzf-android-translation/releases/download/v4.1-release-3/PvZ-Fusion-4.1-English-prerelease3.apk): official online Magic Plantbrush recognition.
- [Offline AI APK](https://github.com/silvershadowkat/pvzf-android-translation/releases/download/v4.1-release-3/PvZ-Fusion-4.1-English-prerelease3-AI.apk): local plant recognition in the separate ENAI app. Uses more memory and a plant-only catalog that does not include every 4.1 plant.

## Install or update

1. Back up your saves, just in case.
2. Install Standard over your existing EN app, or Offline AI over ENAI, without uninstalling.
3. Open the game and continue playing. Progress, extra save slots and settings stay in place.

EN, ENAI and the Chinese app keep separate saves. If moving between apps, follow the [save transfer guide](https://github.com/silvershadowkat/pvzf-android-translation/blob/v4.1-release-3/docs/PROJECT-BACKGROUND.md#moving-saves-without-restoring-old-translation-files). Keep the old app until your transferred saves load correctly.

## What's new

- Fixed runtime translations and settings controls disappearing after an Android restart.
- Fixed an Original intro bypassing Blooms and restored selected-track preloading.
- Added missing descriptions, card effects and changelog wording.
- Kept the Plant Info and screen-mode fixes.

For a larger field view, set Camera Zoom to 5. Original and Blooms music remain available in Settings; close and reopen the game after switching soundtracks.

Some specialized names remain Chinese until a verified translation is available. If you find an issue, [report it](https://github.com/silvershadowkat/pvzf-android-translation/issues) with your device model, mode and a screenshot.
