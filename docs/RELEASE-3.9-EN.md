# PvZ Fusion 3.9 English Android - Release 1

> **Back up your save data before installing.** After installation, restore
> only the save files you need. **Do not restore the `il2cpp` folder or an old
> `global-metadata.dat` file.**

Early public test build based on the official Android 3.9 APK.

- Ported the established 3.8.1 English work to the official 3.9 Android base.
- Completed the broad 3.9 metadata, UI, TextAsset, level-tip, texture, particle,
  font, Almanac, Help, and layout translation passes.
- Added 2,286 exact PC community string matches, 34 PC regex matches, 679
  reviewed Android/reference matches, and 135 validated TextAsset updates.
- Restored the English Odyssey key, Return key, and pause-menu `MENU` texture.
- Shifted modifier Almanac descriptions slightly right to match the regular
  Almanac layout.
- Removed em dashes from player-facing translated text.
- Preserved the official package ID, save compatibility, launcher, DEX,
  permissions, resources, and both `arm64-v8a` and `armeabi-v7a` libraries.
