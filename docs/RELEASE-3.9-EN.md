# PvZ Fusion 3.9 English Android - Release 5

> **Back up your save data before installing.** After installation, restore
> only the save files you need. **Do not restore the `il2cpp` folder or an old
> `global-metadata.dat` file.**
>
> An in-place update preserves app data. A stale external `files/il2cpp`
> override can supersede the APK payload. Remove only that override before the
> first Release 5 launch. Do not remove your save files.
