# PvZ Fusion 3.9 English Android - Prerelease 5

This 3.9 port was cleanly restarted from the known-good 3.8.1 Update 6 Android
baseline, then upgraded with official 3.9 content. Prerelease 5 refreshes it to
the latest PC Bloom English `3.9` translations. Apart from reviewed generic
settings, buttons, and navigation, gameplay terminology follows the PC project;
missing or placeholder PC translations remain in the official language.

It also preserves the corrected Android font/layout, Almanac alignment,
modifier-card formatting, new-save labels, Odyssey key, Return, pause-menu
`MENU`, `LETS ROCK`, 3.9 art/context menus, cleaned credits parchment, and no
player-facing em dashes. The stale `??? (Currently Bugged)` tool-shop label is
now rejected and left untranslated until PC supplies a usable name.

## Install safely

Back up your save files, uninstall the old build, install prerelease 5, launch
once, fully close it, then restore save/progression files only. Do not restore
or modify `il2cpp/` or copy the whole old `files` directory over the new one.

## Testing

Please compare against the PC 3.9 English reference. Report missing PC English,
incorrect wording, broken fonts, clipping/overlap, wrong buttons, missing art,
or broken context menus. Some PC 3.9 translations are unfinished, so Chinese
text alone is not a bug; include the matching PC English text or explain why it
is generic UI that is safe to translate.
