# Android 4.0 English prerelease 3 (local test 1)

Prepared locally on September 23, 2026. Not published or tested on a device yet.

- Added available PC wording for Pyroboros Pot, several changelog names, Snowy Night navigation and a prerequisite message.
- Translated the Almanac's Passive and Intermediate labels, Purgatory availability text, and the Apex: Inferno effect using the existing PC modifier name.
- Included the diagnostic build's four internal metadata restorations and protection checks.

Tactic names and specialized effects still await usable PC wording. Two plant descriptions remain pending because the PC records share an ID. Puzzle labels still need a display-only solution that preserves level-loading names.

The maintainer reported that the earlier diagnostic APK seemed better, but could not confirm the improvement. This build has passed automated checks; gameplay stability still needs device testing.
